## AIM

To create and implement a pure gold material in Unreal Engine using the Material Editor by applying Base Color, Metallic, and Roughness properties.

## Software Required

Unreal Engine

## PROCEDURE

**Step 1**

Open Unreal Engine and create a new Material named:

M_PureGold

**Step 2**

Open the material in the Material Editor.

**Step 3**

Add a Constant3Vector node.

**Step 4**

Set the Base Color values:

R = 1.000
G = 0.766
B = 0.336

**Step 5**

Connect the Constant3Vector node to the Base Color input.

**Step 6**

Add a Scalar Parameter node and set Metallic value to: 1.0
Connect it to the Metallic input.

**Step 7**

Add another Scalar Parameter node and set Roughness value to 0.03
Connect it to the Roughness input.

**Step 8**

Save the material and apply it to a sphere or cube mesh to view the pure gold effect.
